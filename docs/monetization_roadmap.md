# 収益化ロードマップ

各媒体の収益化ラインまでの距離・到達見込み・次の一手を管理する。
`docs/economics.md`（収支モデル）と `config/monetization.yaml`（収益化条件）の上位にある「事業計画」の文書。

- 数値の条件は `config/monetization.yaml`。ポリシーの要約は `docs/platform_policies.md`。
- 「週次所見」欄は経営企画エージェント（`strategy-review`）が毎週月曜に上書きする。
- お金・規約・媒体追加・フォーマット変更に関わる判断はユーザー決裁（エージェントはメール報告のみ）。
