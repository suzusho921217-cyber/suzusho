# 収支モデル（2026-08-30 試算）

前提: $1 = ¥150。動画生成 API の実単価は**契約時に必ず再計算**する。
設計書 §13 の「90日・総投資上限 ¥100,000」を初期検証枠とする。

この文書は `config/budget.yaml` の数字の背景。運用中に実績で上書きしていく。

## 月次投資（低価格モデル運用）

**月 ¥35,000〜50,000。** 動画生成 API が支配的。

| 項目 | 月額 | 備考 |
|---|---|---|
| 動画生成 API | ¥30,000〜45,000 | 180本/月 ＋ リトライ込みで約 250 生成 |
| LLM（企画・プロンプト） | ¥1,000〜3,000 | |
| BGM / SE / 雑費 | ¥2,000〜4,000 | |
| X API | ¥0（当面） | pay-per-use。無料枠で回す間は計上しない |

中価格帯モデルや X API 課金（$200/月）を入れると **月 ¥10〜15 万**に跳ねる。

## 動画 10 秒あたりの単価目安

| 帯 | 例 | 10秒あたり |
|---|---|---|
| 低 | Kling std / Hailuo / Seedance / Sora-2 ベース短尺 | ¥50〜200 |
| 中 | Kling pro / Runway / Sora-2 | ¥200〜500 |
| 高 | Veo 3 / Sora-2 Pro | ¥600〜1,500 |

設計書 §13 の「90日 ¥100,000」は **低価格モデル ＋ リトライ厳格制限 ＋ X API 無料枠**でぎりぎり。

## 回収（最初の 3〜6 ヶ月）

**月 ¥0。** YouTube / TikTok / X の収益化ラインに到達できない。Instagram Reels は日本で直接収益化なし。
この 90 日は収益フェーズではなく R&D。§18 の撤退判断も「絶対値」でなく「改善傾向」で見る。

## 当たった場合（6ヶ月目以降・1ブランドが伸びた前提）

| シナリオ | 月次ネット | 累計損益分岐 |
|---|---|---|
| うまくいく | 収益 ¥10〜40万 − コスト ¥3〜4万 = **+¥7〜36万** | 15〜20 ヶ月目 |
| 微妙 | ほぼトントン | — |
| 失敗（最も確率大） | 収益 ¥0 | 90日レビューで撤退・累計 −¥10〜15万 |

## 効くレバー

1. **動画 API 単価** — 3〜5 倍振れる。最安許容モデル ＋ リトライ上限を機械で強制（`guardrails.check_budget` / `GenerationJob.max_attempts`）。
2. **X API は当面無料枠** — 90 日で約 ¥90,000 の節約。
3. **1 ブランドに寄せる** — §11 の brand_max_ratio 60% は保守的。伸びたら上げる。
4. **Instagram は収益ゼロ前提** — 露出とテスト用と割り切る。

## 次にやること

  `daily_budget` / `monthly_budget` を実値に更新する。
- 運用開始後、`sheets` の Account Daily DB の `daily_api_cost` 実績でこの試算を毎月上書き。
